# 羅密歐與茱麗葉 · 研究室走廊 輔助

楓之谷(含 MapleStory Worlds 的 Artale)羅密歐與茱麗葉組隊任務「研究室走廊」的過關輔助網站。

**關卡規則**:10 層、每層 4 個平台,只有 1 個是對的。站在平台中央附近按 `↑`,錯的會被**瞬間傳送**到最底層(自己跳下去摔下去不算錯)。四個人各在**獨立房間**,隊友成功的平台對你就一定是錯的。

網站做的事:
- **即時推論**每個人每層還剩哪些平台可能,並建議「現在誰該試哪個平台」,同時試的人**不會重複**。
- **螢幕偵測**自己的角色(自動模式),或用按鈕**手動**登記結果(手動模式),兩種可隨時切換。
- 四個人各開一份,用房間代碼**即時同步**結果。
- **收集每一輪的答案**,統計是隨機還是有固定組合,並用歷史資料預測下一層。

## 怎麼開

| 方式 | 作法 |
|---|---|
| 最簡單 | 雙擊 [`dist/maple-rj-helper.html`](dist/maple-rj-helper.html)(單一檔案,可下載給隊友) |
| 本機網站 | `npm run serve` 然後開 <http://localhost:8765> |
| 放上網路 | 整個資料夾丟到任何靜態空間(GitHub Pages 等);螢幕擷取需要 https 或 localhost |

瀏覽器請用 Chrome / Edge。

## 四個人怎麼一起用(重點)

每個人的房間是獨立的,一台電腦的畫面只看得到自己,所以**四個人各開一份網站**:

1. 「隊伍連線」→「我是」選自己的座位(玩家 1~4,四人不能重複)。
2. 房間代碼四人填同一組(可按「產生代碼」再傳給隊友),連線方式選「網路」,按「連線」。
3. 連上後座位列會亮綠燈。之後誰成功 / 失敗、誰在第幾層、誰按了「新的一輪」都會同步。

連不上(公司/學校網路、擋 WebRTC)時,用「分享碼」:一人複製自己的分享碼貼到聊天室,其他人貼進「合併分享碼」。

一個人在同一台電腦多開(多個遊戲視窗)時,開多個分頁,網址後面加 `?profile=1`、`?profile=2`…讓每個分頁有獨立的儲存空間,連線方式選「同一個瀏覽器的分頁」。

## 自動模式(螢幕偵測)

1. **擷取遊戲畫面**:選遊戲視窗(MapleStory Worlds / Artale 視窗)。
2. **校準格線**:畫面凍結後,依序點「第 1 層最左邊平台」「第 10 層最右邊平台」(選填:起點地面)。10 層要同時在畫面內,畫面不能隨角色捲動。
3. **框選自己的名牌**:在「隊伍」自己那列按「框選名牌」,拖曳框住自己角色腳下的名字。不依賴特定介面外觀,直接拿你畫面上的名牌當模板。
4. **開始偵測**。畫面上會畫出格線和追蹤框,「隊伍」裡顯示相似度和目前站的格子;對不準就調「設定」裡的名牌偏移、容許範圍、比對門檻。

偵測規則:
- **失敗**:站在平台上,下一個畫面直接出現在底層、中間沒有任何空中畫面 = 被傳送。自己跳下去會有連續的下墜畫面,**不會**被記成失敗。
- **成功**:畫面上沒有直接訊號,所以用「站著沒被傳走(預設 1.5 秒)」或「往上到下一層」推論;可在設定改成只在往上時推論,或完全關掉改手動。
- 名牌消失又出現在底層(例如被擋住)時,會跳出提示問你是不是那個平台失敗。

## 手動模式

每張建議卡上按「✔ 成功」或「✘ 被傳回底層」登記剛剛試的平台(預設是建議的那個;想改試別的先點卡片上的 ①②③④)。「摔回底層」是自己跳下去,不算平台錯。也可以直接點「平台總覽」的小圓點標記,「復原」和事件紀錄的 ✕ 可更正誤登。

## 規則假設(可在設定切換)

- **每人答案不同(預設)**:同一層四個人的答案各占一個平台。某位隊友成功 → 那個平台對其他人必錯;系統窮舉所有可能的排列來推論,每次失敗或成功都盡量縮小範圍。
- **全隊共用同一答案**:同一層全隊答案相同,系統讓同時試的人各試不同平台。

進去實測一次就知道:同一層你和隊友成功的平台不同 → 互斥。

## 數據統計

每一輪學到的答案路徑會自動存在瀏覽器裡(「數據統計」面板,可關閉)。統計各層分佈是否均勻、**不同輪之間前 N 層答案重複得比隨機多不多**(固定組合的證據)、相鄰兩層是否獨立,資料夠多時給出「像隨機」或「有規律跡象」。若有規律,卡片上會顯示「歷史 N 筆相同開頭,X% 是第 Y 平台」。可匯出 / 匯入 JSON、CSV 合併隊友的資料。示範模擬的資料不會被收集。

## 隱私與連線

- 所有資料只在你的瀏覽器(localStorage)。網站沒有後端。
- 「網路」連線使用 [PeerJS](https://peerjs.com/) 公用的連線協調伺服器(載入 `unpkg.com/peerjs`)只用來讓四台電腦找到彼此,之後結果是電腦對電腦直接傳,不經過伺服器。房間代碼請取不好猜的字串。
- 螢幕擷取只在你的瀏覽器內分析,畫面不會上傳。這個工具只「看」畫面,不會對遊戲送出任何按鍵或操作。

## 開發

```
npm test            # 單元測試(推論、事件引擎、追蹤、統計、同步)
npm run e2e         # 瀏覽器端到端(需先 npm run serve,需要 Playwright)
node test/e2e-room.mjs   # 多台裝置同步的端到端
npm run build       # 重新產生 dist/maple-rj-helper.html
```

結構:`js/solver.js`(推論與建議)、`js/engine.js`(畫面位置 → 成功/失敗事件)、`js/tracker.js`(名牌模板比對)、`js/grid.js`(座標 → 層/平台)、`js/merge.js` + `js/sync.js`(隊伍同步)、`js/stats.js`(規律統計)、`js/ui.js` / `js/app.js`(介面)。

## 已知限制

- 偵測邏輯用合成畫面和單元 / 端到端測試驗證過,**尚未用真實遊戲畫面實測**;名牌相似度、偏移、容許範圍可能需要依你的畫面微調。
- 「網路」連線的傳輸層用模擬的 PeerJS 測過,尚未對真實 PeerJS 伺服器實測。
