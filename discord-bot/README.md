# Artale 小幫手(Discord 機器人)

**完全免費**的 Artale Discord 機器人,指令都是中文:

```
/掉落物 藍寶        → 藍寶掉什麼、出沒哪裡(輸入時會跳出選項,打錯一個字也找得到)
/更新情報           → 馬上調出 Artale 最新的更新與情報
/回報 …             → 新地圖資料還不全?玩家自己補,會標示〔玩家回報〕
/打怪 /賭博 /簽到   → 楓之谷風格的打怪升級、賭博小遊戲
```

不需要任何付費服務,跑在你自己的電腦上就行。(AI 問答是「選用」的付費功能,不開也完整可用。)

| 功能 | 指令 | 說明 |
|---|---|---|
| 🔎 查掉落 | `/掉落物 名稱` | 輸入怪物 → 掉什麼、出沒哪裡;輸入道具 → 哪些怪掉、機率。也可以直接 **@機器人 名稱** |
| 🗺️ 查地圖 | `/地圖 名稱` | 這張地圖有哪些怪物(依等級排序) |
| 📰 情報 | `/更新情報` | 最新的更新與情報,每天自動收集(見「情報」) |
| 🙋 補資料 | `/回報`、`/回報刪除` | 玩家回報資料庫還沒有的掉落、地圖(見「資料不完整時」) |
| 📚 攻略 | `/攻略 主題` | 給你各攻略網站(巴哈、Dcard、PTT…)的站內搜尋連結 |
| ⚔️ 打怪升級 | `/打怪` `/角色` `/背包` `/賣出` `/簽到` `/排行榜` | 打怪賺經驗、楓幣、道具,升級、賣東西、每日簽到(見「小遊戲」) |
| 🎰 賭博 | `/賭博 骰子`、`/賭博 拉霸` | 用**虛擬楓幣**賭一把 |
| 🎲 其他 | `/擲骰` `/抽籤` `/衝捲` `/猜拳` `/猜數字` `/猜怪物` | 贏了有楓幣 |
| ❓ | `/說明` | 看有哪些功能 |
| 🤖 選用 | `/問答`、AI 版 `/攻略` | 要 Anthropic API 金鑰(付費),見最後一節 |

> **這個機器人本身沒有內建任何 Artale 的資料,也沒有預設的情報網址。** 查掉落要先匯入資料庫(見「匯入資料」),或讓大家用 `/回報` 一筆一筆補;`/更新情報` 要管理員先加情報來源(見「情報」)。小遊戲、搜尋連結不需要這些。

## 開始用

### 1. 準備

1. **Node.js 20 以上**。
2. **Discord 機器人**:到 [Discord Developer Portal](https://discord.com/developers/applications) → New Application →
   - **Bot** → Reset Token,複製 token(這是密碼,別貼到任何地方)。預設**不需要**開任何 Privileged Intent(只有「情報頻道」功能需要,見下)。
   - **OAuth2 → URL Generator**:Scopes 勾 `bot` 和 `applications.commands`;Bot Permissions 勾 `View Channels`、`Send Messages`、`Read Message History`。用產生的連結邀請機器人進你的伺服器。
   - **General Information** 複製 Application ID。

### 2. 安裝與啟動

```bash
cd discord-bot
npm install
cp .env.example .env      # 填入 DISCORD_TOKEN 和 DISCORD_APP_ID(其他都可以不填)
npm run register          # 註冊斜線指令(只要做一次;改了設定或更新程式後再做一次)
npm start
```

測試時在 `.env` 填 `DISCORD_GUILD_ID`(你的伺服器 ID),指令會立刻出現;沒填則是全域註冊,最久約一小時生效。機器人要一直開著才會回話,也才會每天自動收集情報(家裡常開的電腦、樹莓派或 VPS 都可以)。

## 匯入資料(查掉落用)

機器人讀 `data/db.json`,用 `npm run import` 從表格產生它。資料來源由你決定:自己整理的試算表,或是別人公開、**允許你使用**的資料。抓別人網站的資料前,請先確認它的使用條款,或問一下維護者。

準備三張表(都可以只做其中幾張,`drops` 這一張就夠開始):

| 表 | 欄位 |
|---|---|
| `monsters` | 怪物、等級、HP、經驗、出沒地圖(多個用 `;` 隔開)、別名、備註 |
| `items` | 道具、類型、別名、備註 |
| `drops` | 怪物、道具、機率(`0.5%`、`1/200` 或 `很稀有` 這類文字都可以)、備註 |

欄位名稱中英文都行(見 `src/lookup/import.js`),多餘的欄位會被忽略。`data/templates/` 有三個範例檔(只是格式示範,請刪掉範例列)。從 Google 試算表用「下載 → CSV(或 TSV)」匯出,放進 `data/raw/`:

```bash
npm run import -- --dir data/raw --source "資料來源說明"
# 或指定檔案:--monsters m.csv --items i.csv --drops d.csv
```

**別名**很有用:在 `monsters` 的「別名」欄寫上玩家平常的叫法(例如暱稱、簡稱),`/掉落物 藍寶` 才找得到 `藍色寶寶` 這類名字。匯入完成**機器人不用重開**,發現檔案改了會自動重讀。

## 資料不完整時:(未知)與〔玩家回報〕

全新的地圖和怪物,掉落資料通常一開始很不齊。機器人不會假裝知道:

- 沒有資料的欄位一律寫 **(未知)**,例如 `Lv.(未知)`、`機率 (未知)`、`出沒:(未知)`。
- 玩家用 `/回報 怪物 道具 [機率] [地圖] [來源]` 補的資料,會標成 **〔玩家回報×人數〕**(幾個不同的人回報過),並附一行「尚未證實」的提醒。
- 匯入的資料如果缺機率,而玩家有回報,會顯示回報的機率並標 `〔機率為玩家回報〕`;已匯入的機率**不會**被回報蓋掉。
- 回報會立刻出現在 `/掉落物` 的結果裡。寫錯可以 `/回報刪除 編號`(自己的,管理員可刪全部)。

防濫用:每人一天最多 15 筆、同一人重複回報同一筆只會更新不會加倍計算、名稱會被清理(去掉 @ 提及和控制字元)、來源只收 http(s) 連結。

## 情報(`/更新情報`)

`/更新情報` 顯示最新的情報:標題(連結)、來源、多久以前。每天早上 6 點(台灣時間,可改)自動去所有來源收集一次,指令被呼叫時如果超過 30 分鐘沒抓過,也會先去抓再回答。**沒有預設來源**,因為我沒辦法確認哪些網址抓得到(見「已知限制」),請管理員自己加:

```
/情報來源 新增 名稱:巴哈 網址:https://forum.gamer.com.tw/B.php?bsn=你的看板編號 關鍵字:Artale
/情報來源 測試 名稱:巴哈          ← 看抓到什麼;沒抓到就調整網址、關鍵字
/情報來源 列表   /情報來源 移除   /情報來源 立即更新
```

新增時會馬上試抓一次並告訴你抓到幾則。這些指令只有「管理伺服器」權限的人能用。來源有三種:

| 類型 | 說明 |
|---|---|
| **RSS / Atom / JSON Feed** | 最穩定。很多網站有,或可以用 RSS 轉換服務(例如自己架的 RSSHub)把不提供 RSS 的網站轉成 RSS,再貼那個網址 |
| **論壇看板網頁** | 貼看板首頁的網址,機器人會把「長得一樣的一大批連結」當成文章列表(巴哈的 `C.php?bsn=…&snA=…`、PTT 的 `M.….html` 這種)。抓不準時用「關鍵字」只收標題含某些字的,或用「連結篩選」(正規表示式)指定連結長相 |
| **Discord 頻道** | `/情報來源 頻道加入 頻道:#某頻道`:那個頻道的貼文會變成情報。想收**其他社群**的公告,可以在對方的公告頻道用 Discord 內建的「追蹤」功能,把公告轉進你自己伺服器的某個頻道,再把那個頻道加進來。需要在 `.env` 設 `ENABLE_CHANNEL_INTEL=1` 並到 Developer Portal → Bot 開啟 **Message Content Intent** |

自動貼到頻道:`.env` 設 `NEWS_CHANNEL_ID`,每天收集完會把**當天新出現的**情報貼過去(第一次只建立基準,不會把舊文章全倒出來)。時間用 `NEWS_DAILY_AT`、時區用 `TZ_OFFSET_HOURS` 調整。

注意事項:
- 對網站很客氣:一天自動抓一次、手動呼叫最快 30 分鐘抓一次,只存標題、連結和一小段摘要,點進去看原文。
- 網址有安全檢查:只允許公開的 http/https 網址,內部網路位址(`localhost`、`192.168.*` 等)和轉址到那裡都會被拒絕。
- 沒有日期的網頁文章會標「(收錄時間)」,意思是機器人第一次看到它的時間。

## 小遊戲

**打怪升級**(資料存 `data/players.json`,每個伺服器各自獨立):

- `/打怪`:每 15 秒一次。遇到的怪物依你的等級而定;**匯入資料庫後用資料庫裡的怪物、經驗和掉落機率**(機率不明的當 3%),沒匯入就用內建的幾隻怪。可以指定地圖(`/打怪 地圖:…`)。贏了得經驗、楓幣和道具,打輸損失一點經驗。
- `/角色` `/背包` `/賣出 道具 [數量]`(輸入「全部」賣光)`/簽到`(每天一次,連續簽到更多;日界線依 `TZ_OFFSET_HOURS`)`/排行榜`。道具賣價由稀有度決定:資料庫裡的機率越低越值錢。
- 小遊戲(`/猜拳` `/猜數字` `/猜怪物`)贏了也會拿楓幣,存進同一個角色。
- 內建怪物和數值是**遊戲平衡用的,不是 Artale 的資料**。

**賭博**:`/賭博 骰子 金額 押注:大/小`(兩顆骰子,7 點莊家通吃,1 賠 1)、`/賭博 拉霸 金額`。**用的是機器人裡的虛擬楓幣,沒有任何現實價值,也不能兌換**,每則賭博結果都會附這句提醒。賭金 10~50,000、每 4 秒一次;設計上莊家長期會贏(拉霸的理論回報率約 89%,有測試驗證),所以不是賺錢的辦法。要不要在你的伺服器開放,請依你的社群規範決定(例如有未成年成員的話)。

**其他**:`/擲骰`(`2d6+3`)、`/抽籤`、`/衝捲`(選成功率和格數的衝捲模擬)、`/猜拳`(按鈕)、`/猜數字`(全頻道一起猜,30 分鐘沒人猜作廢)、`/猜怪物`(看 3 個掉落物猜是哪隻怪,需要資料庫)。

## 部署(Docker,選用)

```bash
docker build -t artale-bot .
docker run -d --restart unless-stopped --env-file .env -v "$PWD/data:/app/data" artale-bot
```

## 安全性

- 機器人的回覆**不會 @ 任何人**:`@everyone`、`@here`、使用者 / 身分組提及都會被破壞掉,client 也設了不解析提及;玩家回報和情報標題裡的 Markdown 會被跳脫。
- 設定情報來源的指令需要「管理伺服器」權限(Discord 端和程式裡各檢查一次)。
- 沒有任何指令能讓使用者存取機器人電腦上的檔案;抓網頁有 SSRF 防護和大小、時間上限。
- 錯誤訊息是白話文,不會洩漏 token 或內部細節。token 只放 `.env`(已被 `.gitignore` 排除)。

## 選用:AI 問答(要付費)

在 `.env` 填 `ANTHROPIC_API_KEY`(到 [console.anthropic.com](https://console.anthropic.com) 申請,並在 Console 啟用 web search)再重新 `npm run register`,就會多出 `/問答`,而且 `/攻略` 和 @機器人 會改成由 AI 查網站後回答、附來源連結。**每次提問都會花錢**(Claude 的 tokens 加上網頁搜尋費),預設有每人 10 分鐘 5 次、一天 40 次的限額和每次的搜尋上限(見 `.env.example`)。`npm run check -- "問題"` 可以不經 Discord 先試試並看用量。這一塊我只用模擬的回應測過,沒有用真的金鑰實測。

## 已知限制

- **沒有用真的 Discord 連線測過。** 開發環境連不到 discord.com,所以:登入、斜線指令註冊、按鈕與自動完成的實際行為都沒有實測。我測了的是:所有指令的邏輯(用模擬的 Discord 物件)、資料匯入與搜尋、玩家回報、RPG 規則、情報流程(含用**真的 HTTP 伺服器**測抓取、轉址、編碼、大小上限)、設定與啟動流程(用假 token 啟動到登入那步)。第一次跑請先在自己的測試伺服器試一輪。
- **沒有驗證過任何真實的情報網站。** 開發環境連不到巴哈、Dcard、PTT、Threads,所以不知道它們實際抓得到什麼。論壇看板的判斷是通用的啟發式,可能要靠「關鍵字 / 連結篩選」調整;請用 `/情報來源 測試` 檢查。
  - **Dcard** 通常用 JavaScript 動態載入且有防機器人機制,直接抓大多會失敗;建議走 RSS 轉換服務,或請有 Dcard 的人把重要文章用 Discord 頻道轉進來。
  - **脆(Threads)、Facebook、Instagram** 要登入才看得到,而且抓取通常違反服務條款,這個機器人**不支援**。能做的是:請看到消息的人用 `/回報` 補掉落資料,或把連結貼進情報頻道。
  - **其他 Discord 社群**:機器人不會偷看別人社群的聊天內容,要對方社群同意。用 Discord 內建的「追蹤公告頻道」是最乾淨的做法(見上)。
- Artale 繁中版官方公告的網址我沒有找到,所以沒有預設來源;知道的話用 `/情報來源 新增` 加進去。
- 資料庫的內容完全取決於你匯入什麼;玩家整理和回報的資料本身可能有錯漏。
- 放音樂已經拿掉了(很多機器人都有)。曾經做過的版本在 git 歷史的 commit `3c5ed86`。
- Docker 映像沒有實際建置測試過。

## 開發

```bash
npm test      # 92 項測試(不需要 Discord 或網路)
```

結構:`src/lookup/`(CSV 解析、匯入、搜尋、資料卡、玩家回報)、`src/news/`(解析 RSS / 網頁、安全抓取、儲存、排程、畫面)、`src/rpg/`(規則、角色儲存、指令)、`src/games/`(小遊戲)、`src/routes.js`(每個指令做什麼)、`src/wiring.js`(Discord 事件)、`src/bot.js`(入口,含每日排程)。AI 選用功能在 `src/agent.js`、`src/handlers.js`、`src/prompt.js`。
